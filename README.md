# 勁戰四代・拆裝學徒

一款在瀏覽器裡玩的 3D 修車遊戲。你是阿德機車行的學徒，要把一台 YAMAHA 勁戰四代（Cygnus-X 第四代，雙碟版）
從頭拆到只剩車架，再把 77 個零件一個一個裝回去，最後加油、轉鑰匙、握煞車、按啟動，一發發動。

## 怎麼玩

線上直接玩：https://sksksk1748.github.io/Scooter_Sim/

也可以下載後用 Chrome 或 Edge 打開 `index.html`（雙擊即可）。第一次載入需要網路，用來下載 3D 引擎 three.js 和字型。

| 操作 | 說明 |
| --- | --- |
| 左鍵拖曳 | 旋轉視角 |
| 右鍵拖曳 | 平移 |
| 滾輪 | 縮放 |
| 點零件 | 拆解時：用目前的工具拆下；組裝時：拿起零件，再點綠色虛影裝上去 |
| 雙擊零件 | 鏡頭對準它 |
| `1`–`0` | 徒手、十字起子、六角扳手、火星塞套筒、氣動扳手、飛輪拔取器、汽門彈簧壓縮器、尖嘴鉗、橡膠槌、珠碗扳手 |
| `Q` `W` `E` `R` `T` `Y` | 8／10／12／14／17／24mm 套筒 |
| `U` | 扭力扳手（組裝時才有） |
| `X` | 透視（試車時是剖面） |
| 試車時 `W` 或 `↑` | 催油門；`H` 喇叭、`K` 鑰匙、`B` 煞車、`S` 啟動 |

進度會自動存在瀏覽器裡，下次打開可以「繼續上次進度」。

## 遊戲內容

- **拆解**：零件之間有真實的前後順序（例如要先拆坐墊、電瓶蓋、電瓶負極才能動其他地方；要先拆導風罩、汽門室蓋、正時齒輪才能拆汽缸頭）。每個零件要選對工具，拆下來的零件會排到零件墊上、貼上紙膠帶標籤。
- **組裝**：順序反過來，從車架開始。汽缸頭、火星塞、普利盤、輪軸、卡鉗這些關鍵螺絲要換成扭力扳手。工單上的「零件托盤」可以直接點選零件。
- **小遊戲**：對正時（T 記號對上死點）、汽缸頭對角交叉鎖緊、加機油（850±50 c.c.）、加齒輪油（130±10 c.c.）、選汽油。
- **阿德師考你**：13 題維修常識，例如先拆電瓶哪一極、火星塞型號、輪胎規格的意思。
- **試車**：發動後引擎內部真的會動——活塞、連桿、曲軸、凸輪、四個汽門、正時鏈條、CVT 普利盤與皮帶變速、離合器、後輪。打開「剖面」和「慢動作」可以看四行程循環。
- **零件爆炸圖**：從標題畫面進入，用滑桿把整台車沿拆裝方向展開，搭配零件圖鑑看每個零件的功能。
- **難度**：學徒（提示工具與順序）、黑手（自己判斷）、師傅（沒有提示、失誤加重）。

## 資料來源與準確度

規格參考公開資料：124cc 單缸氣冷 SOHC 四氣門、缸徑 × 行程 52.4 × 57.9 mm、壓縮比 10.0:1、軸距 1305 mm、
前 110/70-12、後 120/70-12、前碟 245 mm、後碟 200 mm（雙碟版）、雙槍後避震、NGK CR7E 火星塞（間隙 0.7～0.8 mm）、
機油 850±50 c.c.、齒輪油約 130±10 c.c.、電瓶在置物箱與尾燈之間。

3D 模型與拆裝流程是為了教學而簡化的示意，螺絲尺寸、數量與部分零件位置不一定與實車完全相同；
扭力值只列出參考值。實際維修請以原廠維修手冊與專業技師為準。本作品為粉絲自製，與 Yamaha 無關。

## 檔案結構

```
index.html          頁面骨架（three.js 從 jsDelivr 載入）
css/style.css       介面樣式
js/parts-data.js    77 個零件的資料：名稱、功能、工具、拆裝順序、師傅小叮嚀、測驗題
js/model-*.js       程序化 3D 建模（車殼、底盤、引擎、傳動、電系）
js/scooter.js       組車、零件墊排位、高亮／透視／爆炸圖／虛影
js/game.js          遊戲流程與規則
js/run.js           試車：發動流程與引擎運轉動畫
js/audio.js         以 Web Audio 即時合成的音效（工具聲、引擎聲）
```
